01 / DESKTOP APPLICATION / JAVA DESKTOP APP

Steam Builder

↗

A JavaFX desktop application that helps users plan gaming PCs around the Steam games they want to play. The app brings game requirements and component planning into one workflow, making it easier to compare a potential build against a game's hardware needs.

  • Search Steam games and review minimum and recommended specifications.
  • Generate PC build suggestions and check component compatibility.
  • Use AI-assisted build analysis to review build choices.
  • Use Firebase and Cloud Firestore for app data, Maven for builds, Git/GitHub for version control, and jpackage to package a Windows executable.
